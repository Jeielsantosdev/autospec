# autospec

> FastAPI-like automatic OpenAPI generation for Go.

`autospec` é um SDK inteligente para geração automática de documentação OpenAPI/Swagger no ecossistema Go.

A proposta é simples:

* sem annotations
* sem comentários Swagger
* sem boilerplate
* sem duplicação de documentação

O código da aplicação se torna a única fonte de verdade.

---

# O Problema

Hoje documentar APIs em Go ainda é uma experiência extremamente manual.

Ferramentas tradicionais como:

* [Swaggo](https://github.com/swaggo/swag?utm_source=chatgpt.com)
* [Go Swagger](https://goswagger.io?utm_source=chatgpt.com)

dependem fortemente de comentários e annotations:

```go
// @Summary Criar usuário
// @Description Cria um usuário
// @Tags users
// @Accept json
// @Produce json
// @Param request body CreateUserRequest true "Request"
// @Success 200 {object} SuccessResponse
// @Failure 400 {object} ErrorResponse
// @Router /users [post]
func CreateUser(c *gin.Context) {
}
```

Isso gera vários problemas:

* documentação duplicada
* Swagger desatualizado
* muito boilerplate
* perda de produtividade
* manutenção difícil
* experiência ruim para desenvolvedores

---

# O Que o autospec Resolve

O `autospec` traz uma experiência parecida com o FastAPI para o ecossistema Go.

Exemplo no FastAPI:

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class CreateUserRequest(BaseModel):
    name: str
    email: str

@app.post("/users")
def create_user(data: CreateUserRequest):
    return {
        "success": True
    }
```

Automaticamente o framework gera:

* OpenAPI
* Swagger UI
* request schemas
* response schemas
* validação
* exemplos
* documentação interativa

Sem comentários manuais.

# Como Funciona

O `autospec` combina:

| Tecnologia         | Função                 |
| ------------------ | ---------------------- |
| AST Parsing        | entender código        |
| Reflection         | inferir tipos          |
| Runtime Inspection | detectar execução real |

---

# AST Parsing

Usando:

```go
go/ast
go/parser
go/token
go/types
```

O SDK consegue analisar:

* handlers
* structs
* rotas
* requests
* responses

---

# Runtime Inspection

O diferencial principal.

O runtime inspection permite detectar:

* middlewares
* grupos de rotas
* autenticação
* metadata real
* rotas dinâmicas

---

# Exemplo

## Código da aplicação

```go
app := gin.Default()

autospec.Attach(app)

app.POST("/users", CreateUser)
```

---

## Resultado automático

```yaml
/users:
  post:
    requestBody:
      content:
        application/json:
          schema:
            $ref: '#/components/schemas/CreateUserRequest'

    responses:
      '200':
        description: Success
```

Sem comentários Swagger.

Sem annotations.

Sem boilerplate.
